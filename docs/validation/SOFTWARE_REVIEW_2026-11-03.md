## 已发现并关闭的问题

1. **P1 地图档案复扫丢失身份。** 根路由经 MapSheet 透传既有 `launchRescan`，
   详情与行菜单都使用选中树号和根分类。档案关闭后只交接一次；immutable generation
   阻止旧页面动作影响新页面，缺少复扫能力时保留 nil 与原新建扫描兜底。
2. **P2 详情误报缓存完整状态。** 旧逻辑在当前已验证读返回 nil 时回退到列表缓存的 complete。
   现在 `ScanArchiveDetailLoader` 在同一仓储事务内核对真实源文件并读取当前结果、身份、日期、
   类别、置信度与大小；incomplete/invalid 不再显示旧读数。源消失、坏源与其他 IO 故障分别处理。
3. **P2 日期夹具跨月失效。** 宽查询从写死的 2026102 改成稳定的记录号字段；保留明确不命中的
   同树对照档案，补11月与跨年回归，精确计数、滚动、身份和原档保护断言均保留。
