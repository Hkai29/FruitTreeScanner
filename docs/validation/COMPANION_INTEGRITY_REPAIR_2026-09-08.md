# 历史结果与校准导入复查

本轮仅修改伴随结果读取、校准导入及对应回归测试，保留前轮未提交工作。

## 发现与修复

- **P1：数量溢出可导致历史读取崩溃。** `Double(Int.max)` 实际上舍入到 Int 范围外，原先的上界比较仍允许它进入 `Int(raw)`。改为保留整数原始精度，并使用 `Int(exactly:)` 拒绝无法表示的浮点值。覆盖最大合法整数、越界数字及字符串、小数和负数。
- **P1：校准导入绕过事务完整性校验。** 原实现信任历史列表缓存的 complete 状态，直接重读 JSON 基线；文件后来损坏或事务版本不一致时仍可能导入自动校准。现在从共同的伴随文件读取器取得已经验证的基线、算法和上下文，并从同一结果取得水果类别；未知类别不携带自动校准资格。负数或无效基线不导入。
- **P1：缺失完成标记的新格式文件被误判为旧格式。** 含导出版本的新格式 JSON/CSV 必须有有效完成标记。缺失标记时拒绝作为完整结果；不含导出版本的原有历史格式继续支持。
