# 扫描产量架构修复与 Review

## 本轮完成

### 证据关联

ValidatedFruit 新增 sourceCandidateIDs。FusionValidator 输出明确候选身份，三维轨迹合并保留源 ID 并集。估重优先消费这些候选，不再把已绑定果实重新匹配到无关的近邻；绑定候选丢失时转入明确的重量回退。无身份的兼容调用仍允许距离匹配，使用固定 ID 顺序减少排列依赖，但这不能补回历史上已丢失的身份。

复现案例修复后两种顺序均为 0.54119176 kg，均匹配 2 个几何。轨迹合并保留两个源候选 ID 的测试通过。

### 重量回退与质量

VisibleYieldEstimate 显式记录 fallbackFruitCount。生产结果组合将重量结果传入质量评估：全部回退为 manual_review，部分回退最高 medium，并在结果 note 中说明回退数量及品类均值来源。

6 个融合结果、无候选几何的案例仍保守保留 1.2 kg 默认估计，但等级由 high 改为 manual_review，避免冒充实测重量。检测证据仍可用于计数；未修改 fused 接纳规则。

### 校准版本隔离

CalibrationRecord 新增可选 algorithmRevision。缺失字段的旧 JSON 可正常解码，原记录继续保留。生产扫描只应用当前算法版本的记录；缺少版本及旧版本记录仅作对照。

版本由估算结果自身携带并导出。Review 中修正了“导出时直接盖当前版本”的方案，避免重导出旧结果被误标为新算法。新校准记录从已完成扫描的结果元数据继承版本；估算值或品类等被修改后不再继承。纯手动输入保留作对照，界面明确说明限制，旧记录也标明未参与当前自动校准。

## 仍需验收及架构边界

- 本轮质量合成处理了默认重量回退，尚未统一所有几何质量、遮挡与校准不确定性。
- 当前算法版本为明确版本标识；模型权重、全部参数快照和校准原始基线的完整兼容策略仍需后续完善，不能把该标识视为完整实验复现记录。
- 历史导入数据无法凭空恢复源候选身份；兼容路径仍应作为低可追溯性路径看待。
- 尚未进行校准界面端到端操作及真机扫描/称重；停止时在途证据丢失、长扫描性能等既有问题仍未关闭。
