# Documentation

This directory keeps project documentation out of the repository root while preserving the material needed for engineering, validation, and research.

```text
validation/      Real-device acceptance, ground-truth protocol, and commercial readiness notes
reference/       Longer technical reference documents
implementation/  Implementation plans and working notes
paper/           Paper-oriented supporting material
aris-skills/     Local academic-writing skill references used during research drafting
superpowers/     Planning/spec artifacts from earlier workflows
```

The user-facing project overview remains in `../README.md`.
