# Research Materials

This folder holds manuscript and research-planning material that supports the project but is not required to build the iOS app.

```text
PAPER_*.md/docx  Draft manuscript exports
chapters/        Complete chapter drafts
paper/           LaTeX/Word paper workspace
plan/            Research outline, evidence map, and chapter plans
```

Keeping these files here makes the repository root read like an app project while preserving the academic work.
